# 运行时模型

运行时负责已编译图的持久化生命周期。它记录足够的执行证据，以便检查运行过程，并在暂停或进程重启后安全继续。

## 核心记录

- **Run** 记录生命周期状态、图标识、修订版本、时间和失败详情。
- **Event** 记录有序的执行证据，例如节点完成和检查点创建。
- **Checkpoint** 保存稳定执行边界上的可恢复状态。
- **Artifact** 保存与 Run 关联的较大输出或诊断材料。

## Run 生命周期

Run 从准确的 Graph Session 和初始状态开始。运行时依次推进节点、应用经过验证的状态补丁、发布事件，并在配置的边界创建检查点。

Run 可以完成、失败、取消，也可以因断点或用户输入而暂停。恢复前会验证检查点是否与图契约兼容。

## 确定性状态更新

节点通过补丁返回状态变更。顺序补丁按执行次序应用；只有当并行分支写入互不重叠，或使用已注册的确定性 reducer 时，
它们才会被合并。

## 检查运行

使用 Workbench 或调试服务器 API 检查 Run 摘要、分页 Events、Checkpoints、Artifacts 和选定的状态快照。
本地配置方式参见 [Workbench](/zh/guides/workbench)。
